Starshipit connection and local data.

Starshipit API

Keys are stored only in this browser. Direct calls to the Starshipit API are usually blocked by browsers (CORS) — the README ships a 20-line Cloudflare Worker proxy that makes the live connection work. Until then the dashboard runs on demo data.

Local data

—

Everything lives in this browser (localStorage + IndexedDB) — nothing is sent to a server. Use Export backup to move or share the database; it downloads a single JSON file including uploaded documents.
